# WOMBAT Explorer branding

Transparent header and compact assets prepared from the supplied WOMBAT Explorer reference using imagegen edits. The mascot/globe composition and lettering style are retained; WOMBAT uses warm cream for contrast on the navy header. These are reference-derived edits, not the original source pixels.

WebP derivatives use quality 0.96 and preserve alpha. Full assets are 480/960 px wide; compact assets are 192/384 px square. Favicons are transparent 32/64 px PNGs. No CSS mascot, emoji, opaque backdrop, raster-map filter, or GIS changes are involved.
